# Product Overview

This is a **Modern Gemini Chat Application** - a comprehensive web-based chat interface for Google's Gemini AI models.

## Core Purpose
- Provide a professional, dark-themed chat interface for Gemini AI
- Support multimodal interactions (text, images, files, URLs)
- Enable context-aware conversations with file/folder/URL integration
- Maintain persistent conversation history with SQLite database

## Key Features
- **35+ Gemini Models** - Full access to available Gemini AI models
- **Real-time Streaming** - Server-sent events for live message delivery
- **Context Integration** - File, folder, and URL context processing
- **Conversation Management** - Multiple persistent chat threads
- **Multimodal Support** - Image, audio, video file processing
- **Security** - Sandboxed file access within `allowed_context` directory
- **Modern UI** - Dark theme with Tailwind CSS, responsive design

## Target Users
Developers and users who need a feature-rich, local Gemini AI chat interface with advanced context capabilities and professional UI.
